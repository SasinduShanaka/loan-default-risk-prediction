# Loan Default Risk Prediction

A machine learning project developed for the **IT3051 – Fundamentals of Data Mining** mini project.

The goal of this project is to analyse historical loan data and develop a classification model that can predict a loan's `Status` based on borrower, loan, credit, and property-related characteristics.

---

## Project Objective

Financial institutions face risk when borrowers fail to meet their loan obligations.

This project applies a complete data mining and machine learning workflow to:

- Understand the loan dataset
- Perform exploratory data analysis
- Identify data-quality issues
- Detect possible data leakage
- Preprocess numerical and categorical features
- Engineer and select useful features
- Compare multiple classification algorithms
- Perform hyperparameter tuning
- Select a final model based on experimental results
